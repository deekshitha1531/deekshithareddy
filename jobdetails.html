Python Developer

Tech Solutions Pvt Ltd

📍 Bangalore 💼 Full Time 💰 ₹5 - ₹8 LPA

Job Description

We are looking for a motivated Python Developer to join our development team. The ideal candidate should have a good understanding of Python, databases and web development.

You will work with experienced developers to design, develop and maintain web applications using modern technologies.

Responsibilities

  • Develop and maintain Python applications.
  • Write clean, reusable and efficient code.
  • Work with databases such as MySQL and PostgreSQL.
  • Develop and integrate REST APIs.
  • Troubleshoot and fix application issues.
  • Work with the development team to deliver projects on time.

Requirements

  • Good knowledge of Python programming.
  • Basic knowledge of Flask or Django.
  • Understanding of HTML and CSS.
  • Knowledge of SQL databases.
  • Good problem-solving skills.
  • Freshers are welcome to apply.

Required Skills

Python Flask SQL HTML CSS REST API Git

  • Competitive salary
  • Learning and development opportunities
  • Flexible working environment
  • Career growth opportunities
